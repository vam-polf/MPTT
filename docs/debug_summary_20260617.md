# MPTT WM8960 无声调试总结

## 根因定位

**PA10(I2S2_SD) 外部有强下拉 ≈ 0V/0.7V**

实验验证：
1. MCU 复位后 PA10 模拟模式 → IDR=0（外部拉低）
2. PA10 输入上拉(40kΩ) → IDR=0（下拉强于上拉）
3. PA10 GPIO 输出高 → IDR=1（MCU 驱动可以克服）
4. PA10 I2S AF 模式 → 0.7V（I2S AF 驱动弱于外部下拉）

排除项：
- ❌ 不是 WM8960 ADCDAT（DIGENB=0 关数字核心后仍然拉低）
- ❌ 不是 I2S 配置问题（不启动 I2S 也一样）
- ❌ 不是代码问题（MCU 复位后无任何代码运行就拉低）

## 嫌疑对象

1. **E77 模组内部 SX1262 MISO** — 如果 PA10 在模组内部连到 SX1262 SPI MISO
2. **PCB 漏电/短路** — PA10 走线对 GND 有意外连接
3. **WM8960 ADCDAT 始终输出低** — 即使 ADC 全关、数字核心关

## 软件尝试记录

| 修改 | 结果 |
|------|------|
| R7 0x002→0x004 (I2S 格式) | 无效 |
| DIGENB=1→0 (关数字核心) | 无效 |
| VU latch toggle | 无效 |
| ADCDAT pull-up (R9 bit4) | 无效 |
| PA10 内部上拉 (PUPDR) | **待验证** |

## 建议的硬件修复（按优先级）

### 方案A: PA10 外加 1kΩ 上拉到 3.3V（最简）
- 在 PA10 和 VDD(+3.3V) 之间焊一个 1kΩ 电阻
- 提供给 I2S AF 输出额外的上拉驱动

### 方案B: ADCDAT 串联电阻限流
- 在 WM8960 pin16(ADCDAT) 到 PA10 之间串 10kΩ
- 降低 ADCDAT 对 PA10 的下拉能力

### 方案C: 彻底断开 ADCDAT
- 切断 PA10 到 WM8960 pin16 的走线
- 放弃录音功能，只保留播放
